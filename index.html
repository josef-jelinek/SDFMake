Script Syntax

Units are millimeters. Scripts are let assignments, let macro declarations, and one final render expression. The final expression is rendered directly; object is an ordinary assignment name with no special behavior.

let size = 50
let center = [0, 0, mul(size, 0.5)]
let base = box(center, size)
let cut = cylinder([15, 15, 25], 8, 70)
subtract(base, cut)

The z axis is vertical, and the build plane is z = 0. Material below the build plane or outside the configured volume size is removed. Comments start with # or //. Number, list, and shape assignments are compile-time constants and must use let name = expression. A 3D vector is a list with exactly 3 numeric items used where a primitive or operator expects a vector. List, function argument, and macro parameter lists can include one optional trailing comma before the closing ] or ).

Macros And Blocks

Macros are compile-time substitutions. Declare them with let, parameters, =, and either a single expression or a scoped block.

let pair(a, b) = union(a, b)
let cut_with(base, cutter) = {
let moved = move(cutter, [0, 0, 2])
subtract(base, moved)
}

pair(box([0, 0, 10], 20), cut_with(box([0, 0, 10], 20), sphere([0, 0, 12], 4)))

Macro names cannot replace built-in names. Macro parameters shadow outer names inside the macro body, while passed arguments resolve where the macro is called. Recursive macros are rejected. Blocks end with a direct result expression.

Lists And Loops

Lists are compile-time values. Use [a, b, c] to create a list and ... inside function calls to pass list items as separate arguments.

let min_val = min(...[1, 2, 3, 4])
let spheres = for i = 0 to 10 step 2 sphere([mul(i, 5), 0, 20], 2)
let moved = for item in spheres move(item, [0, 10, 0])
smooth_union(...moved, 4)

Range loops are inclusive. Inline loop bodies use the next expression directly. Braced bodies are scoped blocks and return their final expression.

Primitives

  • sphere(center, radius)
  • box(center, size). size can be a number or vector.
  • rounded_box(center, size, edge_radius) keeps the box dimensions and rounds each edge inward.
  • box_frame(center, size, thickness) creates an open rectangular frame following the twelve box edges. size can be a number or vector.
  • chamfer_box(center, size, chamfer_size) keeps the box dimensions and clips each edge inward with flat chamfers.
  • cylinder(center, radius, height), centered on the z axis.
  • rounded_cylinder(center, radius, height, edge_radius) keeps the cylinder radius and height and rounds the cap edges inward.
  • chamfer_cylinder(center, radius, height, chamfer_size) keeps the cylinder radius and height and clips the cap edges inward with flat chamfers.
  • tri_prism(center, radius, height), hex_prism(center, radius, height), and octagon_prism(center, radius, height) create centered z-axis prisms with regular polygon cross sections.
  • cone(base_center, height, base_radius, top_radius)
  • rounded_cone(base_center, height, base_radius, top_radius, edge_radius) keeps the cone side profile and rounds the base and top edges inward.
  • chamfer_cone(base_center, height, base_radius, top_radius, chamfer_size) keeps the cone side profile and clips the base and top edges inward with flat chamfers.
  • pyramid(base_center, height, base_size) creates a square pyramid with its base centered at base_center and apex at base_center + [0, 0, height].
  • octahedron(center, size) creates a centered regular octahedron.
  • torus(center, major_radius, minor_radius), centered around the z axis.
  • capped_torus(center, major_radius, minor_radius, start_degrees, sweep_degrees) creates a rounded tube along a partial torus arc in the xy plane. Positive sweep is counter-clockwise when viewed from +z.
  • capped_cylinder(start, end, radius) or capped_line(start, end, radius) creates a rounded tube between two 3D points.
  • capped_cone(start, end, start_radius, end_radius) creates a flat-capped tapered cone between two 3D points.

Operators

  • union(a, b, ...) combines volumes. intersect(a, b, ...) keeps the overlap.
  • subtract(a, b, ...) removes all following volumes from the first volume.
  • smooth_union(a, b, ..., radius), smooth_intersect(a, b, ..., radius), and smooth_subtract(a, b, ..., radius) blend operations with a mandatory final smooth radius.
  • chamfer_union(a, b, ..., radius), chamfer_intersect(a, b, ..., radius), and chamfer_subtract(a, b, ..., radius) create flat 45-degree chamfers with a mandatory final chamfer size.
  • color(a, [r, g, b]) assigns a linear RGB color from 0 to 1 for the Solid and Solid photo previews.
  • min(a, b, ...), max(a, b, ...), add(a, b, ...), and mul(a, b, ...) combine two or more values. For colored shapes, min keeps colors like union and max keeps colors like intersect.
  • abs(a), div(a, b), mod(a, b), and pow(a, b) provide primitive value operations.
  • move(a, offset) moves a shape by a vector.
  • scale(a, factor) and scale(a, scale_vector) scale a shape around the origin.
  • rotate(a, axis, angle_degrees) rotates a shape around an axis vector through the origin. Facing in the axis direction, positive angles rotate clockwise.
  • round(a, radius) rounds a surface outward.
  • shell(a, thickness) creates a shell around a surface.

Triangulators

  • Voxel: classifies full grid cells by sampled occupancy, keeps sharp cube faces, and adds 10 percent bridge geometry only where edge-touching or corner-touching cells are not already face-connected through neighboring voxels.
  • Voxel blend: assembles half-shifted junction tiles from the eight neighboring voxel states. Exterior and interior voxel transitions are blended with sloped facets, so exposed 90 degree and recessed 270 degree voxel junctions are replaced. Diagonal point contacts are left as separate chamfered corners instead of being bridged.
  • Marching tetrahedra: splits every grid cell into five tetrahedra with alternating 3D chessboard orientation and connects shared grid-edge crossings directly. Edge vertices are clamped away from tetrahedron corners using a reducer-derived weld threshold, which avoids closure triangles smaller than the reducer can keep distinct.
  • Contour fit: samples the SDF on a grid. When the surface crosses a grid cell, it uses the edge crossings and surface normals to fit one representative vertex inside that cell, then connects neighboring fitted cell vertices across crossing grid edges. This preserves sharp edges and corners better than using the edge crossings directly.

Page Controls

  • Editor: update the script to recompile the preview after a short pause. Solid and Solid photo shaders compile lazily when their view is needed, and the previous selected shader stays active until its replacement is ready.
  • Triangulate: create a mesh from the current SDF script, then run the selected reducer in background workers.
  • Preview: switch between Solid, Solid photo with heavier ray-marched lighting, Shaded mesh with AO, Triangle mesh with false coloring and AO, and Wireframe mesh. Mesh AO fades outside the central volume area to avoid distant ground and horizon darkening. If no mesh exists, mesh previews show a grayscale Solid preview and start triangulation when clicked.
  • Export txt STL: download the current triangulation as an ASCII STL file.
  • Export bin STL: download the current triangulation as a compact binary STL file.
  • Triangulator: choose Voxel, Voxel blend, Marching tetrahedra, or Contour fit before triangulating.
  • Reducer: choose None to keep the raw triangulation, Edge collapse to collapse geometry-preserving edges from shortest to longest, or Strong edge collapse to allow up to 3 degrees of local plane deviation while keeping the same topology guards.
  • Cell size: set triangulation cell size in millimeters. Default is 1 mm, and the minimum is 0.1 mm.
  • Subdivisions: for Contour fit, set the minimum feature size to cell size divided by subdivisions. For Voxel and Voxel blend, sample this many subcells on each axis to measure cell occupancy. Marching tetrahedra does not use subdivisions, so the input is disabled for that mode. Default is 2, and the maximum is 3.
  • Triangulation progress: mesh generation and selected reduction run in background workers and report progress in the preview overlay.
  • Volume size: set the width, depth, and height in millimeters of the visible triangulation volume. Its height starts at the z = 0 build plane, and the final object is clipped to this box. The Solid preview draws a faint volume wireframe, and Solid plus mesh previews subtly darken the volume footprint on the ground. Triangulation adds at least 1 mm of hidden padding on all sides before sampling, then expands the sampling grid to whole cells aligned on the origin.
  • Preview drag: rotate the camera around the object.
  • Mouse wheel: zoom the preview camera.
  • Animate: slowly orbit the camera around the object.
  • Grid: the preview grid is the z = 0 build plane with 10 mm cells.
  • Dark mode: switch the page theme between light and dark mode.
